# Test corpus: inert fixtures, not malware

This folder holds **test fixtures** for Agent Shield's evaluation and test suite.

- `malicious/`: **inert stubs** that only *demonstrate* attack patterns (prompt injection, `curl | sh`,
  exfiltration, unsafe pickles, risky agent configs) so the scanner has something to detect.
  - Every script exits before its payload (`exit 0`, `sys.exit(0)`, `process.exit(0)`, `raise SystemExit(0)`);
    `tests/test_corpus.py` enforces this.
  - URLs use the reserved `.invalid` TLD, TEST-NET IPs (192.0.2.0/24, 203.0.113.0/24) or dummy paths.
  - Pickle files only *reference* dangerous callables, or call a harmless one (`os.getcwd`). Never load them anyway.
- `clean/`: legitimate samples, including hard cases (security tutorials, deploy-key docs) that look suspicious to
  regexes.

Each sub-directory is one labelled sample. Binary and invisible-Unicode samples are generated by
`build_corpus.py`. Do not copy these files into a real agent, skills folder or MCP config.
